# ♠ Покер-Школа

Техаський Холдем з навчанням, тренуваннями і тренером. Працює в браузері на комп'ютері й телефоні, після першого відкриття — навіть без інтернету.

## 🤖 Автогра «Claude грає»

За тренувальним столом («Гра з тренером») натисніть кнопку **🤖** на панелі столу: за вас гратиме алгоритм і коротко пояснюватиме кожен хід у вікні «Claude грає». **⏸** — пауза (ходите ви), **—** — згорнути, **✕** — вимкнути, темп — Повільно / Норм. / Швидко. Логіка — у `js/autopilot.js`.

## 🗺️ Кар'єра і 🎟️ Покер-пас

- **Кар'єра** (`js/career.js`): турне 8 містами, дуелі один на один з босами, у кожного свій стиль (Скеля, Маніячка, Липучка…). Перша перемога дає ексклюзивний предмет, якого немає в магазині, і відкриває наступне місто.
- **Покер-пас** (`js/pass.js`): сезон триває календарний місяць, у ньому 30 рівнів. Зірки дають за роздачі, тренування, завдання, уроки й дуелі. Преміум-доріжка коштує 5 000 🪙 і дає сезонні ексклюзиви, які зникають після кінця сезону.

## Як викласти на GitHub Pages (без встановлення програм)

1. Зайдіть на https://github.com → **New repository** → назва, наприклад, `poker-school` → **Public** → **Create repository**.
2. На сторінці репозиторію натисніть **uploading an existing file**.
3. Перетягніть у вікно **весь вміст** папки `Pocker` (файли `index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`, `README.md` і папки `css`, `js`, `icons`) → **Commit changes**.
   - `.nojekyll` — прихований файл; якщо Провідник його не показує, його можна пропустити.
4. **Settings → Pages** → *Source*: **Deploy from a branch**, *Branch*: **main**, папка **/ (root)** → **Save**.
5. За 1–2 хвилини гра буде за адресою `https://<ваш-логін>.github.io/poker-school/`.

## Як встановити на телефон

- **Android (Chrome):** відкрийте посилання → меню ⋮ → **Додати на головний екран / Встановити застосунок**.
- **iPhone (Safari):** відкрийте посилання → кнопка **Поділитися** → **На початковий екран**.

Гра відкриватиметься на весь екран, як звичайний застосунок. Прогрес (монети, рівень, уроки) зберігається на самому телефоні.

## Оновлення гри

Після зміни файлів завантажте їх у репозиторій заново і в `sw.js` збільште версію (`poker-school-v1` → `poker-school-v2`), щоб телефон точно підхопив нову версію.
